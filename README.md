# 나 혼자만 캐시업

한림대 "게임과 스포테인먼트 콘텐츠" 조별 프로젝트입니다. 카카오뱅크 × 나 혼자만 레벨업 콜라보 **26주 헌터 양성 적금**의 모바일 앱 프로토타입입니다.
가입자는 성진우를 26주 동안 키웁니다. 매주 납입하고 걸으면 E급에서 S급으로 자라고, 26주를 다 채우면(S급) 우대금리를 받습니다. 모든 스토리는 원작과 별개인 콜라보 한정 IF 설정입니다.

- 웹: https://cashup-sololevel.vercel.app (발표용)
- 최종 기준: 포스터(2026.11.22). 기획안 문서(2026.11.14)와 다르면 포스터를 따릅니다.

## 동선과 화면

카카오뱅크 안에 있는 상품이라는 느낌이 들도록 **카카오뱅크 홈 → 혜택(이벤트) → 콜라보 적금 페이지 → 가입 → 개설 완료 → 적금 상세** 순서로 들어갑니다.
카카오뱅크 화면과 가입 단계는 실제 카카오뱅크 앱(홈, 26주적금 가입·상세 화면) 구성을 참고했습니다.

| 화면 | 내용 |
| --- | --- |
| 카카오뱅크 홈 | 맨 위 알림 칩("나 혼자만 캐시업 출시 · 최고 연 7.0%") · 파란 대표 통장 카드(가짜) · 계좌 목록 카드(가입 전 '적금 추가', 가입 후 적금 줄) · 카드. 하단 탭은 홈·혜택만 열림 |
| 혜택 | 콜라보 배너(던전 그림) + 진행 중인 이벤트 목록(시연용 예시) |
| 콜라보 적금 페이지 | 던전 키 비주얼(콜라보 표기·제목) → 최고 연 7.0% · 기본 연 2.0% 두 칸 → 이렇게 키워요 → 성진우의 26주 성장(E~S·히든 각성·리워드 예정) → 상품 안내. **여기부터 던전 BGM** |
| 가입 | 헌터 선택(성진우 · 차해인·백윤호는 시즌 2 실루엣으로만) → 약관 확인 → 도전 금액(1천~1만 원씩 매주 증액) → 자동이체 요일·출금 계좌(가짜) → 길드(새로 만들기 / 받은 초대 코드로 참여) → 만기 예상원금 요약 |
| 개설 완료 | 출금 알림 · 시작금액 · 자동이체 · 만기일 · 적용금리 · 길드 → 헌터 협회 등록 창 |
| 적금 상세 · 홈 | 던전 무대(이번 주 도전 금액 · 성진우 · 그림자 병사, 누르면 상태창) → 이번 주 납입 버튼 → 페널티 게이트(미납 시) → 26주 도전 현황(도장판) → 만기 예상 금리 → 헌터 등급(다음 등급 조건 · 리워드 예정) |
| 적금 상세 · 우대금리 | 만기 예상 금리 · 수령액(지금 조건 / 남은 우대 모두), 우대 1 S급 달성, 우대 2 길드 구간 |
| 적금 상세 · 걷기 | 오늘 8,000보 퀘스트, 히든 각성 게이지, 이번 주 걷기 |
| 적금 상세 · 길드 | 이번 주 길드 퀘스트(전원 납입 진행 막대) · 함께하는 헌터(등급 · 각자 주차 또는 수료 · 이번 주 납입 · 2주 연속 미납이면 '독려하기') · 다음 구간까지 인원 · 구간표 · 길드 소식 · 초대 코드. 길드원은 모두 시연용 가짜 데이터(`lib/guild.js`) |
| 페널티 퀘스트 | 유예권 확인(네 줄 요약) → 게임 고르기 한 화면(두 게임 카드: 조작법·기준 점수) → 30초 플레이(아래 띠가 점수판) → 결과(내 점수 / 기준 점수) → 통과하면 재납입 |
| 연출 | 원작풍 시스템 알림 · 등급 상승(새 등급 크게, E→D는 곡괭이가 부서지고 첫 무기, 이후는 무기 강화, 병사 합류) · 히든 각성(만기 · 걷기 EXP 10,000 이상: 그림자 병사 5명 → 보랏빛 섬광과 함께 무릎 꿇은 벨리온(조원 그림) → 그림자 군단 완성) · 프로젝트 수료(받는 금액 · 완납/미납/걷기 · 히든 각성) |

모든 화면은 시연용입니다. 실제 계좌·비밀번호·개인정보 입력칸은 없습니다.

## 디자인 원칙

- **바탕은 카카오뱅크**: 흰 섹션을 8px 회색 띠로 나누는 구조, 노란 주 버튼, 본문은 Pretendard. 둥근 카드를 같은 여백으로 쌓지 않는다
- **나혼렙은 포인트로만**: 원작풍 시스템 창(파랑·금·빨강), 던전 무대·키 비주얼, 등급 배지, 페널티 게임. 나혼렙 서체(HeirOfLight)는 창 제목·대사·등급 글자·큰 제목·게임 시간에만 쓰고 설명과 표는 고딕
- **색은 넷**: 검정(글자) · 카뱅 노랑(주 버튼) · 나혼렙 보라(진행·강조) · 위험 빨강(미납). 등급 색은 등급 배지에만
- **글자 단계**: 26(큰 숫자) / 17(섹션 제목) / 15(본문) / 13(보조) / 12(주석)
- **피하는 것**: 이모지 아이콘, 장식용 그라데이션, 알약 라벨 남발, 가운데 정렬 일색, 늘 움직이는 애니메이션(별 반짝임·포털 숨쉬기 같은 배경 정도만)
- **한 화면에 주인공 하나**: 적금 홈은 던전 무대 + 바로 아래 납입 버튼, 결과는 받는 금액, 승급은 새 등급 글자

## 상품 규칙 (CLAUDE.md와 같음)

- 기간 26주, 시작 금액 1천~1만 원, 매주 같은 금액씩 증액 (만기 원금 35.1만~351만 원)
- 금리: 기본 2.0% + 길드 우대 최대 2.0%p + S급 달성(26주 완납) 우대 3.0%p = **최고 7.0%**
- EXP: 주간 납입 +1,000 / 하루 8,000보 +100
- 등급(EXP와 완납 주차 동시 충족): E 0 / D 5,000(5주) / C 10,000(10주) / B 15,000(15주) / A 20,000(20주) / S 26,000(26주)
- 성진우: 등급이 오를 때마다 그림자 병사 1명(이그리트·탱크·아이언·어금니·베르)
- 히든 각성: 만기까지 걷기 보너스 EXP 10,000 이상이면 최종 연출(벨리온) + 추가 리워드(예정)
- 보상: 등급 달성 시 카카오페이 포인트·카카오페이지 캐시 (예정)
- 길드: 초대 코드로 만들거나 받은 코드로 참여. 파티 2~5명 +0.5%p / 공격대 6~14명 +1.0%p / 길드 15~29명 +1.5%p / 연합 길드 30명 이상 +2.0%p
- 길드 무임승차 방지(기획안): 2주 이상 연속 미납한 길드원은 만기 정산 때 인원에서 빠짐. 앱에서는 경고와 '독려하기'로만 보여 주고, 지금 금리 계산은 바꾸지 않음
- 길드원마다 주차가 다름: 26주를 채운 길드원은 '수료'로 남아 인원에 계속 들어감. 길드 우대금리는 각자 자기 만기 때 그 시점 인원으로 확정. 이번 주 길드 퀘스트는 이번 주에 납입할 차례인 길드원만 대상
- 미납: 페널티 게이트, 미납 유예권 2장(1장당 1회), 미니게임 통과 후 재납입하면 완납으로 인정

규칙 숫자는 [`src/lib/rules.js`](src/lib/rules.js) 한 곳에만 있습니다. 바꾸면 화면 문구도 따라 바뀌고, `npm run test`가 규칙대로인지 확인합니다.

## 캐릭터 그림 바꾸기

그림은 `src/assets/character/` 에 있습니다. 성진우는 E급 그림(`hunter-e.png`)과 D급부터 쓰는 성장 그림(`hunter-up.png`) 두 장이고,
그림자 병사 5명(이그리트·탱크·아이언·어금니·베르)은 한 장씩입니다.
[`src/lib/characters.js`](src/lib/characters.js) 의 `HUNTER_ART`(E~S 순서)와 `SHADOW_ART`만 바꾸면 홈 무대·배너·가입 화면·승급 연출·상태창·미니게임에 모두 반영됩니다.
원본은 SVG지만 한 장에 1~3MB라, 배경을 비우고 캐릭터 크기로 잘라 PNG(헌터 높이 600px, 병사 400px)로 바꿔 넣었습니다.

## 사운드

외부 음원 없이 Web Audio로 합성합니다([`src/lib/sfx.js`](src/lib/sfx.js)).
- 효과음: D단조·낮은 음·긴 잔향의 던전 톤. 카카오뱅크 화면의 버튼 소리는 짧고 조용하게
- BGM: 콜라보 적금 페이지부터 낮은 드론 + 느린 패드(Dm–B♭–Gm–A) + 먼 북소리 + 가끔 종소리 + 바람. 카카오뱅크 홈·혜택과 페널티 게임(자체 BGM) 중에는 꺼짐
- 적금 상세 오른쪽 위 스피커 버튼이나 M 키로 효과음·BGM을 함께 끄고 켭니다

## 실행

Node.js 20 이상이 필요합니다.

```sh
npm install
npm run dev      # http://localhost:5174
npm run test     # vitest
npm run build    # dist/ 에 배포용 파일 생성
npm run preview  # 빌드 결과 미리 보기
```

## 배포 (GitHub → Vercel)

`main`에 push하면 Vercel(`cashup` 프로젝트)이 자동으로 다시 배포합니다. 설정은 `vercel.json`에 있습니다.
가끔 push했는데 자동 배포가 시작되지 않을 때가 있습니다. 그럴 때는 작업 폴더에서 직접 운영 배포합니다.

```sh
vercel --prod
```

예전 주소 `cashup-livid.vercel.app`이 아직 프로젝트에 붙어 있습니다. 지우려면 Vercel 대시보드 → cashup → Settings → Domains에서 Remove.

## 시연 컨트롤 (발표용)

모든 폭에서 폰 화면 오른쪽 가장자리의 **시연** 손잡이를 누르면 리모컨 서랍이 밀려 나오고, 화살표로 다시 넣습니다. 열어 둔 채 버튼을 연달아 눌러도 왼쪽 화면에서 알림·승급 연출이 바로 보입니다. 넓은 데스크톱(780px 초과)에서는 폰 옆 패널도 함께 보입니다.

가입한 뒤에 씁니다. 다음 날 · 다음 주 · 5주 빠르게 · 이번 주 미납 · 길드원 +1/+5 · 25주로 이동 · **만기 · 히든 각성 바로 보기**(열린 게이트 재납입 → 남은 주 납입 → S급 승급 → 히든 각성 → 수료 결과) · 전체 초기화(카카오뱅크 홈부터 다시), "건너뛴 날은 8,000보를 걸은 것으로" 체크.

적금을 개설하고 적금 홈에 처음 들어오면 '헌터 협회' 창으로 두 장짜리 안내가 뜹니다. 1장은 나 혼자만 레벨업이 어떤 이야기인지, 2장은 헌터 등급 · 그림자 병사 · 시스템 창 · 페널티 게이트가 이 적금에서 무엇인지 설명합니다. 나혼렙을 모르는 사람도 바로 이해하도록 하는 용도이고, 가입할 때마다 뜹니다(초기화 후 다시 가입해도).

링크 미리보기: `index.html`의 og 태그 + `public/og.png`(1200×630).

## 미정

- 페널티 퀘스트 통과 기준(지금은 점수제 임시: 던전 러닝 1,500점 · 독충 회피 240점)
- 등급별 리워드 품목, 히든 각성 추가 리워드 (앱에는 '(예정)'으로만 표시)
- 성진우 등급별 그림 (지금은 E급 · 성장(D~A) · S급 세 장, `characters.js`의 `HUNTER_ART`에서 교체)
- 시즌 2 헌터(차해인 · 백윤호) 그림 — 지금은 선택 화면 실루엣만
